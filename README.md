# ExamPath India — Starter Website

A beginner-friendly static website for government-exam practice, built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — website structure
- `style.css` — responsive styling
- `script.js` — category filters, quiz timer, scoring, answer review
- `questions.js` — sample question data

## Run locally
Open `index.html` in a browser. If your browser blocks local scripts, use the Live Server extension in Visual Studio Code.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `exampath-india`.
2. Upload all four files to the repository's root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment to finish. Your public URL will be shown in Settings → Pages, typically `https://YOUR-USERNAME.github.io/exampath-india/`.

## Before publishing
- The included questions are demonstrations, not verified previous-year questions.
- Verify all answers and exam-specific marking rules.
- Link to official question papers or only reproduce materials you have permission to share.
- This is a static demo: it has no secure accounts, server database, cloud sync, or admin panel. Local browser storage is not implemented in this starter.
- The site uses Google Fonts from an external service; system fonts will be used if unavailable.
